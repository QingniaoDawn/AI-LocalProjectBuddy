# 本地项目小能手 — 使用说明

> 版本 1.0.0 ｜ 适用平台：Windows 10 / 11（64 位）｜ 形态：绿色免安装

---

## 一、整体用途

**本地项目小能手**是一个 Windows 桌面绿色程序，作用是把「本地电脑里的项目文件夹」变成网页 AI（ChatGPT 网页版、Google Gemini、Grok 等）能直接**读、搜、改、调用**的工具集。

简单说：你在网页上跟 AI 说话，AI 可以"伸手"到你的本地项目目录里读文件、搜代码、改文件、跑命令——所有操作都在你本机发生，**原始数据不上传第三方服务器**，AI 只是按需取回要看的文本片段。

**适用场景**

- 让 ChatGPT 直接帮你读、改本地代码仓库；
- 让 Gemini 帮你整理、总结本地的资料/文档；
- 让 Grok 帮你搜、抽取本地项目里的关键信息。

**不适用场景**

- 不适合做大规模文件同步（它是按需调用工具，不是网盘）；
- 不适合需要 GUI 实时交互的任务（AI 拿到的是文本结果，不是可视化）。

## 二、核心亮点

1. **零配置启动**：双击运行后自动拉起本地 HTTP 服务，并通过 Cloudflare 临时隧道暴露一个公网 HTTPS 地址，复制即可使用，无需注册 Cloudflare 账号。界面操作只需四步：选择文件夹 → 选择权限 → 点启动 → 复制地址。
2. **三档权限可控**：
   - 只读审阅：查看项目结构、搜索、读文件、看 git 状态与差异，不能改任何内容；
   - 允许编辑：+ 写文件、精确补丁、删除文件/目录、从网址下载；
   - 开发模式：+ 运行命令 / 构建 / 测试、执行 git 提交（用本机权限，需谨慎）。

   权限档位在「启动连接」那一刻确定，运行中切换不生效，需停止后再启动。
3. **跨模型同协议**：同时支持 ChatGPT 开发者模式插件、Gemini Spark 自定义应用、Grok 自定义连接器，对接方式一致（都是粘贴同一个 MCP URL），学会一个就会三个。
4. **工具集完整**：提供读、搜、写、补丁、命令执行等 10 余个 MCP 工具，覆盖日常本地项目协作所需。
5. **绿色版交付**：直接拷贝程序文件夹到任意 Windows 机即可运行，无需安装、无需写注册表、无需管理员权限。
6. **下载自动导入**：浏览器下载到"下载目录"的文件，会自动导入项目 assets 文件夹。
7. **多层安全防护**：路径围栏（AI 无法越出项目目录）、SSRF 防护、token 鉴权、日志脱敏、完整性自校验（防篡改）。
8. **手绘玻璃拟态界面 + 实时日志**：每一步工具调用都实时显示在日志页，全程透明。

## 三、主要功能与使用方法

### 3.1 启动连接（首次使用四步）

1. 点「📁 选择文件夹」，选定你要开放给 AI 的项目目录；
2. 在权限区选择档位（默认「只读审阅」）；
3. 点「🚀 启动连接」，等待界面出现公网地址卡片；
4. 点「📋 复制整串地址」，含后半段 token 一起复制。

关闭程序：直接关窗口即可，所有进程会被一起清理。

### 3.2 选择工作目录

首次启动会让你选择一个项目文件夹，那就是 AI 能访问的全部范围。**建议选一个具体的项目子目录**，不要选 C 盘根目录或桌面，否则 AI 能扫到的范围太广，既慢又危险。

### 3.3 可用工具（AI 侧可直接调用）

| 工具 | 作用 |
|---|---|
| `workspace.inspect` | 检查工作区基本信息（大小/文件数/索引状态） |
| `files.list` | 按目录列出文件 |
| `files.recent` | 列出最近被改动/创建的文件 |
| `files.search` | ripgrep 引擎搜索（带上下文行、文件名消歧） |
| `files.read` | 读单个文件（>8MB 自动流式） |
| `files.read_many` | 一次读多个文件 |
| `files.fetch` | 抓取 URL 内容 |
| `files.write` | 写入文件（带 .bak 自动备份） |
| `edit.patch` | 精确补丁（跨行/大文件/多文件事务回滚） |
| `dev.patch_and_test` | 改完后自动跑回归测试 |
| `git.*` | 版本控制工具组（status / diff / log） |
| `run.*` / `shell.run` | 隔离命令执行（已剥离敏感环境变量） |

### 3.4 工具调用的实际使用样例

- *"帮我在项目里搜所有用了 md5 的地方"* → AI 内部调 `files.search`，几秒返回带文件名+行号的结果
- *"把 src/a.js 里 function foo 改成 function bar"* → AI 内部调 `edit.patch`，先做指纹校验、再原子写入，失败自动回滚
- *"帮我跑一下 npm test"* → AI 内部调 `shell.run`（隔离环境），返回 stdout/stderr

### 3.5 切换项目 / 本地直连 / 停止 / 日志

- **切换项目**：运行中点「选择文件夹」选新目录即可热切换，公网地址不变；
- **本地直连**：进阶选项，额外提供一个 127.0.0.1 本地地址（不经公网），适合本地 CLI / Agent 低延迟接入；
- **停止连接**：点「⏹ 停止」即断开，旧地址立即失效，下次启动生成新地址；
- **查看日志**：日志页实时显示每条工具调用与写入记录，支持搜索，最多保留最近 800 行。

## 四、三平台对接步骤

### 4.1 对接 ChatGPT 网页版

> 前提：必须先开启「开发者模式」，否则创建插件会一直失败。

1. **开启开发者模式**：网页账户设置 → 账户安全与登录 → 下拉到「开发者模式」→ 打开右侧开关。
2. **进入插件页**：左侧菜单点「插件」→ 右上角「+」新建（也可点程序界面右侧「打开 chatgpt.com/plugins ↗」跳转）。
3. **填写插件信息并创建**：
   - 名称：随便填，自己能认出来即可
   - 描述：留空
   - 连接：选「服务器 URL」，把隧道完整地址粘进去
   - 身份验证：选「无」
   - 勾选底部「我了解并希望继续」→ 点击「创建」

   常见提示：OpenAI 会显示"未对此 MCP 服务器进行审查…"——固定提示，勾选"我了解"即可，与程序无关。
4. **权限放行**：创建成功后进入插件详情页，点右上角「允许所有操作」；想更安全可只勾选「低风险操作」（只读类）。不放行的话每次 AI 调用工具都会弹窗确认，体验很差。
5. **新对话中 @ 插件**：新建对话 → 输入框按 @ → 选刚创建的插件 → 正常说话即可。@ 一次即可，同一会话多次调用不需要重复 @。

**与 ChatGPT 对接的流畅度（真实使用感受，不夸大）**：

- 单次工具调用延迟约 2-5 秒（隧道 + ChatGPT 思考 + 工具执行），比手动切窗口操作快得多，但比网页搜索慢；
- 上下文消耗：单条 1MB+ 文件读取会迅速消耗上下文窗口，建议先 `files.search` 定位再用 `files.read` 精确读；
- 多文件改动：`edit.patch` 走事务（all-or-nothing），任何一步失败自动回滚；
- 隧道中断：ChatGPT 显示工具调用错误，但聊天不受影响；程序端自动重连，复制新地址重新填即可；
- 回合制说明：网页 AI 每轮回复完会停下等你输入（网页产品行为），发"继续"即可进入下一轮；
- 偶发"界面在动但没干活"：长会话后 AI 端连接器偶发失联，回复正常但本机日志无新请求，发"重新连接工具"或开新对话即恢复——**本机「日志」页是判断真相的唯一依据**。

### 4.2 对接 Grok

1. **进入连接器页**：左侧「技能和连接器」→ 中上「连接器」标签 → 右上「新连接器」。
2. **选自定义 → 填地址**：弹出层里点「自定义」（顶部第一项）→ 名称随便填 → 把完整隧道地址粘到「服务器 URL」→ 点「添加连接器」。
3. **新对话 @ 调用**：新建对话 → 输入框按 @ → 选刚创建的连接器即可。Grok 的连接器添加即时生效，无需单独做权限放行。

### 4.3 对接 Google Gemini（Spark）

1. **进入"已关联的应用"**：左下角账户设置 → 技能 → 左侧「已关联的应用」→ 页面下拉找到「适用于 Spark 的自定义应用」（或点「自定义应用」）。
2. **粘贴地址 → 关联**：输入框粘贴完整隧道地址（以 /mcp/ 结尾）→ 点「下一个」→ 点「下一步」→ 勾选了解 → 点「关联」。
3. **在 Spark 对话里 @ 调用**：顶部切到 Spark 模式（不是普通对话）→ 新建对话 → 按 @ → 选刚添加的应用即可。

> 三种模型对接的共同点：都是粘贴同一个 MCP URL，差别只在网页端菜单位置不一样。每次重启程序地址会变，三平台需重新配置一次新地址。

## 五、注意事项

1. **选工作目录要谨慎**：程序只会让 AI 访问你选的那个文件夹。但 AI 的命令会真的执行——如果你让它删文件，它就会真删。建议先用临时目录试手。
2. **路径与权限边界**：symlink 越界、穿越目录会被直接拒绝；不在工作目录内的文件 AI 完全看不到。
3. **权限档位启动时锁定**：在「启动连接」那一刻确定，运行中切换不生效，需停止后再启动。
4. **隧道地址会过期**：Cloudflare 临时隧道每次重启程序或网络抖动后地址都变。AI 端连不上多半是地址过期，复制最新地址重填即可；程序会自动尝试重连并刷新界面地址。
5. **地址 = 钥匙**：公网地址含 token，不要发到群聊/截图或公开日志；停止连接后旧地址立即失效。
6. **大文件性能**：默认不缓存 >8MB 的文件，超大文件 patch 走流式（内存占用降约 8 倍）；但 100MB+ 单文件依然很慢，建议拆分成小文件。
7. **大文件修改用精确补丁、长命令用后台运行**：让 AI 用 `edit.patch` 增量改，避免整文件重写；长命令让 AI 用 `run.start` 启动 + `run.read` 增量读取，别阻塞单次请求。
8. **命令执行安全**：默认已剥离 authorization / cookie / bearer 等敏感环境变量；但不会拦截 `rm -rf` 这类不可逆命令，请自己选好隔离目录。
9. **ChatGPT 免费账号限额**：开启开发者模式 + 接入含文件类工具的连接器后，免费档会把该对话线程计入"涉及文件/图像"计量桶，更容易触顶；触顶后开新对话即可重置，升级 Plus/Pro 可解除。此限制是 OpenAI 的计量策略，与本程序无关。
10. **切换项目/新对话后等待约 8 秒**：AI 端连接器需重新激活，等本机提示消失后再发首条消息。
11. **完整性自校验**：程序文件被修改或篡改时启动会弹警告（默认退出）。
12. **拷贝分发**：整个「本地项目小能手」文件夹一起拷贝才能运行，单独 exe 不行。
13. **并发与稳定性**：同一时间建议只在 1-2 个 AI 会话里调用工具；关闭程序前先停 AI 端调用。

## 六、常见问题排查

**Q：程序双击无反应？**
A：检查 Windows Defender / 杀毒软件是否拦截。首次启动需手动放行。

**Q：复制地址后 AI 端连不上？**
A：依次检查：
1. 程序主窗口是否仍在前台运行（不是最小化到托盘被关了）；
2. 复制的地址是否完整、是否带 `/mcp/` 后缀；
3. 本机网络是否能访问 trycloudflare.com（部分校园网/企业网会拦截）；
4. 隧道地址是否已过期（重启过程序就会过期）。

**Q：AI 看不到某些文件？**
A：检查：1) "工作目录"是否选对了；2) 文件是否在 `.git` / `node_modules` / `.cache` 等忽略目录里；3) 文件名是否带特殊字符。

**Q：AI 改坏了文件，能恢复吗？**
A：`edit.patch` / `files.write` 默认生成同目录 `.bak` 备份，把 `.bak` 改回原名即可。

**Q：ChatGPT 弹"无法验证 MCP 服务器"？**
A：正常提示，勾选"我了解并希望继续"即可，这是 OpenAI 的固定提示，与程序无关。

**Q：能同时多个人用吗？**
A：可以，但需要把同一个隧道地址分别填到每个人的账号里。隧道是共享带宽，人多会慢。
